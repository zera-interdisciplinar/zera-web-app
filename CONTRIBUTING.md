# Como contribuir

Crie uma branch para cada assunto e use mensagens no padrão Conventional Commits, como `fix: corrige busca`. Abra um pull request descrevendo a alteração e os testes realizados.

Antes de enviar, execute `npm run lint`, `npm test` e `npm run build`. Nunca inclua credenciais ou arquivos `.env` no Git. Os pull requests são incorporados com commit de merge, sem squash.
